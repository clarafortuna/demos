Project scope

Design, develop, and implement a technology solution to support CLCPA initiatives: a DAC/EJ analytics dashboard, automation workflows, and advanced analytics for metrics tracking, analysis, and regulatory reporting. The application is built as a highly customized model-driven solution within the Microsoft Power Apps ecosystem, leveraging Microsoft Dataverse as the core data layer and deployed within Con Edison's enterprise cloud environment.

Objectives

  1. Establish a unified DAC Impact analytics and reporting framework.
  2. Design and build a DAC Impact dashboard with emissions, equity, and DAC metrics.
  3. Implement a structured data intake and tracking application to support ongoing reporting.
  4. Align data definitions and metrics to CLCPA and Environmental Justice requirements.
  5. Deliver strategic guidance and a Phase 2 roadmap for expanded DAC Impact capabilities.

Solution components

  • Server-side business logic (C# plugins within Dataverse) and client-side scripting (JavaScript/TypeScript).
  • Workflow orchestration via Power Automate with custom logic and expressions.
  • Custom data models, relational schema design, and optimized SQL-based querying.
  • REST/JSON API integrations for secure data exchange.
  • Validation frameworks, audit logging, and governance controls.
  • Embedded analytics integrations (e.g., Power BI).

Key definitions

Core terms used throughout this engagement and its deliverables.

DAC Impact Dashboard
A centralized analytics solution that visualizes emissions, program benefits, DAC impacts, and regulatory metrics.
DAC (Disadvantaged Communities)
Disadvantaged Communities as defined by New York State and NYSERDA. CLCPA requires that 35 to 40 percent of program benefits flow to these communities.
Environmental Justice (EJ)
Frameworks and metrics used to evaluate equitable distribution of program benefits.
DAC Impact Intake Application
A Power Apps or equivalent form used to capture, validate, and track DAC Impact related data submissions.
Analytics Platform
An analytics and visualization platform approved by Con Edison, which may include Microsoft or Google-based tools.
Post-Delivery Refinement
A limited support period following delivery during which Clara Fortuna addresses clarification requests and minor refinements related to delivered analytics artifacts.
