Data Sources

What each kind of data on the DAC map is, where it comes from, what a file has to satisfy, and how it is updated.

Tract Shapes

What this data is

The census tract boundaries the map draws. Each set carries a GEOID vintage; the map draws the set whose vintage matches the active DAC Indicators version, so there is nothing to switch here.

Authoritative source. U.S. Census Bureau cartographic boundary files, six Con Edison counties. Neighborhood names come from the newest crosswalk holding each tract.

File requirements

  • A .json dataset file with schema 1.
  • The manifest kind must be the geometry kind.
  • Exactly 8 properties per tract. A file with a different count is refused.
  • A declared GEOID vintage. Several vintages are published at once by design.
  • The record field count must equal the field count in the file.
