DAC Map: Data Sources & Reproducibility

Provenance of every value shown on the “DAC Tracts” map, and how map_payload.json is rebuilt from the original sources.

The map renders 2,333 census tracts across Con Edison’s six-county service territory. Each tract carries its NYS Disadvantaged-Communities (DAC) designation and scores, the underlying environmental / health indicators, Con Edison customer counts, and a neighborhood label. This page documents where each piece comes from (Part 1) and the exact build pipeline so the dataset can be reproduced from the downloaded sources (Part 2).

Part 1

Data sources

NYS Disadvantaged Communities (DAC) data

NYSERDA · NYS Climate Justice Working Group

  • ProvidesDAC designation, Combined Burden Score, statewide rank, the Environmental Burden & Population Vulnerability component scores, and the ~45 underlying indicators (air, traffic, land use, climate, health & demographic percentiles).
  • VintageDAC criteria finalized March 27, 2023. Dataset: “Final Disadvantaged Communities (DAC) 2023.”
  • Datasetdata.ny.gov/Energy-Environment/Final-Disadvantaged-Communities-DAC-2023/2e6c-s6fp
  • Portal / mapnyserda.ny.gov/ny/Disadvantaged-Communities
  • In the dataDownloaded as Data/NYS_DAC.geojson (1,736 statewide DAC tracts, 67 fields each).

Census tract geometry

U.S. Census Bureau

  • ProvidesTract polygon boundaries (the shapes drawn on the map) and the 11-digit GEOID that keys every join.
  • Vintage2020 cartographic boundary files, with 2010 boundaries as a fallback for ~150 legacy-GEOID tracts that have no 2020 equivalent (tracked per-feature in _geom_year).
  • URLcensus.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.2020.html

NYC Neighborhood Tabulation Areas (NTA) crosswalk

NYC Department of City Planning · NYC Open Data

  • ProvidesA 2020 census-tract → neighborhood (NTA) mapping, used to label each NYC tract with its neighborhood name.
  • Vintage“2020 Census Tracts to 2020 NTAs and CDTAs Equivalency.”
  • URLdata.cityofnewyork.us/City-Government/2020-Census-Tracts-to-2020-NTAs-and-CDTAs-Equivale/hm78-6dwm
  • In the dataDownloaded as Data/2020_Census_Tracts_to_2020_NTAs_and_CDTAs_Equivalency_20260601.csv (GEOID column already in 11-digit form).

Con Edison customer data

Con Edison, internal (Disadvantaged Communities Report)

  • ProvidesPer-tract Electric & Gas extracts: customer accounts, EAP enrollment, and bill adjustment, plus the Non-DAC borough aggregates (nondac_by_county).
  • VintageReporting period per the Con Edison DAC Report (internal). Confirm against the authoritative report (see footer).
  • MethodPer the report’s methodology, customers were mapped to census tracts (GEOID) via the NYC Geo-Service for the five boroughs and the Census API for Westchester, then matched to NYSERDA’s published DAC tracts.
  • AccessNot public, sourced from Con Edison internally.
Part 2

How the map data is built & how to reproduce it

The map loads a single file, map_payload.json, a GeoJSON FeatureCollection of 2,333 tract features plus a top-level nondac_by_county aggregate. It is produced in three steps from the sources above. The join key throughout is the 11-digit GEOID (state 36 + county FIPS + tract), and everything is filtered to the six Con Edison counties: Bronx, Kings, New York, Queens, Richmond, Westchester. (Note: Data/build_payload.py builds a separate file, payload.json, for the dashboard’s section tables/charts. It is not part of the map pipeline.)

0

Data/build_base_map_payload.py: build the base map_payload.json

Joins three sources on the 11-digit GEOID, restricted to the six Con Edison counties:

(a) Census-tract geometry. U.S. Census Bureau 2020 cartographic boundary file cb_2020_36_tract_500k, with the 2010 file gz_2010_36_140_00_500k as a fallback for the ~150 legacy GEOIDs that have no 2020 equivalent. Both are filtered to the six counties and saved as Data/ny_tracts.geojson (2020) and Data/ny_tracts_2010.geojson (2010). Each tract uses its 2020 boundary where one exists, otherwise the 2010 boundary, recorded per feature in _geom_year (2,183 → 2020, 150 → 2010). The 2010-vintage tracts are absent from the 2020 NTA crosswalk, so they receive no neighborhood in Step 2.

(b) NYSERDA DAC dataset (Data/NYS_DAC.geojson): DAC designation and the base scores (Comb_Sc, Rank_State, Burden_Pct, Vulner_Pct, Energy_Aff, population/household counts).

(c) Con Edison extracts (Data/Electric.xlsx, Data/Gas.xlsx): per-tract accounts, EAP enrollment, and bill adjustment; Non-DAC borough totals are rolled up into nondac_by_county.

  • Inputs Data/ny_tracts.geojson · Data/ny_tracts_2010.geojson · Data/NYS_DAC.geojson · Data/Electric.xlsx · Data/Gas.xlsx
  • Output map_payload.json: 2,333 features (1,059 DAC + 1,274 Non-DAC), ~20 base properties each, + nondac_by_county. Hybrid 2020+2010 geometry.
1

Data/enrich_map_payload.py: add the granular DAC indicators

Loads Data/NYS_DAC.geojson, filters it to the six Con Edison counties, indexes it by GEOID, then left-joins 48 fields onto each tract: a DAC tract with a GEOID match copies the values; every other tract (Non-DAC, or no match) gets those 48 fields set to null (so the schema is uniform across all 2,333 features). The 48 fields are the 44 indicator percentiles (Environmental Burdens, Climate Risks, Health, Demographics) plus 4 secondary rankings/scores (Rank_NYC, Rank_ROS, Burden_Sc, Vulner_Sc). Fields already on the base (e.g. Comb_Sc, Burden_Pct, Vulner_Pct) are not duplicated; OBJECTID, Shape__Area, Shape__Length and five classification fields (REDC, NYC_Region, Urb_Rural, Trib_Desig, HH_Low_Cnt) are excluded. Idempotent.

  • Inputs Data/NYS_DAC.geojson · map_payload.json
  • Output map_payload.json (overwritten, minified), now ~68 properties per tract
2

Data/enrich_neighborhoods.py: add borough + neighborhood

Backs up map_payload.json → map_payload.backup2.json (once), then loads the NTA crosswalk CSV indexed by GEOID. For every tract it sets borough (display name from County: Kings→Brooklyn, New York→Manhattan, Richmond→Staten Island, etc.) and neighborhood: NYC tracts get the NTAName from the crosswalk; Westchester tracts use City_Town with the “ city” / “ village” suffix stripped; anything with no match (the 2010-vintage tracts) is null. Idempotent.

  • Inputs Data/2020_Census_Tracts_to_2020_NTAs_and_CDTAs_Equivalency_20260601.csv · map_payload.json
  • Output map_payload.json (overwritten, minified) · map_payload.backup2.json

Run order

# from Coned/CLCPA/ExecutiveDashboard_dev/
python Data/build_base_map_payload.py # 0. base build (geometry + DAC + ConEd extracts)
python Data/enrich_map_payload.py   # 1. add 48 DAC indicator / score fields
python Data/enrich_neighborhoods.py  # 2. add borough + neighborhood

Re-running the pipeline on the same inputs reproduces the same result: all three steps are idempotent (each re-derives its fields from the source files on every run).

Reproducibility. The geometry inputs come from the public Census files above and are committed, already filtered to the six counties (Data/ny_tracts.geojson, Data/ny_tracts_2010.geojson); Data/NYS_DAC.geojson and the NTA crosswalk are public as well. Only Data/Electric.xlsx and Data/Gas.xlsx are internal Con Edison data and are not committed to the repo. Drop them into Data/ to run Step 0; everything else regenerates from the public sources.

Definitions

Indicators (percentiles)
Statewide percentiles, 0 to 100. Higher = more disadvantaged relative to all New York census tracts.
Combined Burden Score
A composite total (≈ 0 to 143), not a percentile = Environmental Burden score + Population Vulnerability score. The higher the score, the greater the overall disadvantage; this is the score NYS uses to rank and designate DACs.
EAP
Energy Affordability Program, Con Edison’s bill-discount assistance program; “EAP enrolled” counts accounts enrolled in it.
“Outside ConEd service area”
A tract where Con Edison does not provide that utility (e.g., gas in Brooklyn / Staten Island, which is served by National Grid). Such tracts show no accounts for that utility.
